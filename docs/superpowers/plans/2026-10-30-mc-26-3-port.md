# MC 26.3 "Wilderness Bound" Port Plan (2026-10-30)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Port the mod from Minecraft 26.2 to 26.3 (latest stable, Sep 15 2026) across code, data, tests, and docs.

**Architecture:** Three parallel research spikes (breaking changes, codebase exposure, dependency coordinates) → version bump → 4 parallel fix agents by error domain (input, entity APIs, blocks, items/misc) → vanilla-jar-verified data rewrite (worldgen/loot/biome/advancement) → full gates.

**Tech Stack:** Java 25, Gradle 9.5.1, Architectury plugin 3.5.170, loom-no-remap 1.17.493, Architectury API 22.0.5, NeoForge 26.3.0.99, Fabric Loader 0.20.1.

## Global Constraints

- Stay on the 26.3 line; do NOT touch 26.4 snapshots (Fabric API `0.165.1+26.4` etc. exist and must be avoided).
- No behavior change: API migrations must preserve exact old semantics (verified via `javap` against 26.2 vs 26.3 jars, including `-c` bytecode comparison where signatures alone were ambiguous).
- `runHarnesses`, `runGameTestServer`, `buildAll`, `git diff --check` remain the release gates.
- Do NOT retune GameTest tick budgets in this port (see Verification: flake follow-up).

## Code migrations (all `javap`-verified)

1. **GLFW removed (SDL3):** `org.lwjgl.glfw` gone. `GLFW.GLFW_KEY_*` → `InputConstants.KEY_*` (SDL scancodes; e.g. `KEY_A=4`, was 65). `LEFT_CONTROL` → `KEY_LCONTROL`. `InputConstants.Type.KEYSYM` removed → `Type.KEYBOARD`. Files: 3 key-mapping classes + `ArmyFieldCommandScreen` switch on `event.key()`.
2. **`LivingEntity.swing(InteractionHand)` → `swing(hand, animation, bool)`:** attacks use `swingForAttack(hand)`; interactions use `swing(hand, stack.getInteractAnimation())`. `Player.drop(stack, bool)` → `drop(stack, bool, Prediction.SERVER_ONLY)`. Files: `GalacticRecruitEntity`, `ArmyCombatBehaviour`, `RecruitMeleeCombatBehaviour`, `CommandCenterOperationsMenu`, `MountFiberRecoveryEvents`.
3. **SBL-adjacent vanilla removals:** `Level.fuelValues()` gone → `stack.has(DataComponents.COOKING_FUEL)` (matches vanilla furnace bytecode). `BlockStateBase.blocksMotion()` gone → inlined exact 26.2 body (`isSolid && != COBWEB && != BAMBOO_SAPLING`). Files: `GalacticRecruitEntity`, `ArmyRuntimeEvents`.
4. **Block codecs removed:** deleted `CODEC`/`codec()` overrides (`simpleCodec` gone; verified absent on `Block`/`BlockBehaviour`/`BaseEntityBlock`; vanilla `FurnaceBlock` declares none). `CommandCenterBlock.playerDestroy(Level,Player,…)` → `(ServerLevel,ServerPlayer,…)`. `UntintedParticleLeavesBlock` ctor gains `AmbientLeavesBlockSoundPlayer` (`noAmbientSound()`). `RandomState.sampler()` → `GenerationContext.biomeResolver()`/`climateSampler()`. `ConfiguredFeature`/`Registries.CONFIGURED_FEATURE` gone → `TreeGrower(String, WeightedList, WeightedList, WeightedList, key)` + `ResourceKey<Feature>`/`Registries.FEATURE`.
5. **Item tools data-driven:** `AxeItem/HoeItem/ShovelItem` deleted → `new Item(p.axe/shovel/hoe(tool,dmg,spd))` (same arg order as old ctors; sword/pickaxe pattern already in file).
6. **Render extensions (NeoForge):** `IClientItemExtensions.applyForgeHandTransform` now takes `PlayerRenderState` (not `LocalPlayer`); `player.tickCount` → `player.avatarRenderState.ageInTicks`. `PoseStack.mulPose(Quaternionfc)` removed → `rotate(...)` (PoseStack itself did NOT move packages).
7. **GameTests:** `Entity.setInvulnerable(bool)` split → `setPermanentlyInvulnerable(bool)` (old semantics) / `setInvulnerableTime(int)`; 24 sites updated. `TestData` 11-arg ctor removed → 12-arg with explicit `Level.OVERWORLD` dimension (matches old default per `-c` bytecode).

## Data migrations (verified against vanilla 26.3 jar contents)

- `worldgen/configured_feature/*.json` → `worldgen/feature/*.json`, flattened (`config` inlined; verified: vanilla `ore_iron.json`/`oak.json` have no `config`), ore states → plain strings, `Name` → `id` (0 `Name` hits in 240 vanilla features).
- Loot tables (34): `functions` → `modifier`, `conditions` → `condition` (verified: vanilla `diamond_ore` uses singular; 0 plural hits in 1452 vanilla tables), single-element arrays unwrapped, added `random_sequence`, silk-touch refs modernized to `minecraft:tool/can_silk_touch`.
- Biomes (4): top-level `spawners`/`spawn_costs` removed → `attributes.minecraft:gameplay/natural_mob_spawns.overlay` (verbatim vanilla `desert.json` shape); counts → int or `uniform{min_inclusive,max_inclusive}`.
- Advancement `recipes/credit_chip.json`: `recipe_unlocked` condition `recipe` → `recipes` (verbatim vanilla recipe advancement).
- Unchanged after vanilla comparison: `placed_feature`, `structure`, `structure_set`, `dimension`, `dimension_type`, `biome_modifier`, tags.
